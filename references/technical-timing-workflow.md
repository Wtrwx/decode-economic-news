# 多周期技术择时工作流

本工作流用于 A 股、ETF 和候选股票的 5 日/20 日入场时机与风险参考。它是因果研究、基本面与催化剂之后的**交易时机叠加层**，不是独立预测器。

## 适用顺序

1. 先完成标的身份、实时暴露、观察日、预测周期和事件时钟。
2. 重大事件分支先核验原稿并冻结事件前价格；无重大事件分支先读取本地预期状态。
3. 完成板块分数、候选筛选、新闻/披露、基本面、估值和催化剂研究。
4. 对拟进入条件推荐的每只标的运行本工作流。
5. 技术状态或样本外门禁不通过时，只能 `观察等待` 或 `回避`，不能用叙事信心覆盖。

## 当前状态

```bash
python3 scripts/compute_trade_timing.py work/technology-history.json \
  --asset-code 688001 --asset-code 688002 --benchmark-code 515000 \
  --output work/technology-trade-timing.json
```

输出为 `evidence.signal/1`、`signal_type=trade_timing`。核心状态：

| 状态 | 含义 | 推荐门禁 |
|---|---|---|
| `triggered` | 完成周线和日线同向，收盘突破 prior 20/55 日通道且量能/OBV确认 | 可进入回测门禁 |
| `retest` | 近期有效突破后回踩突破位并收回 | 可进入回测门禁 |
| `triggered_unconfirmed` | 突破但量能/OBV未确认 | 观察 |
| `watch` | 距 20 日通道上沿不超过 2.5%，等待收盘确认 | 观察 |
| `extended` | 距 MA20 超过 8% 或突破后超过 2ATR，追价风险高 | 观察，等待消化 |
| `trend_only` | 多周期趋势一致但没有新触发 | 观察，不把趋势当入场点 |
| `mixed` | 周线和日线冲突 | 观察 |
| `blocked` | 周线空头、日线破坏或突破失败 | 不买/复核 |
| `insufficient_data` / `missing_series` | 数据不足 | 不给方向 |

唐奇安通道严格排除决策当日。未完成周线默认排除在高周期门禁外，并在输出中单列。形态、缠论和常见振荡指标不进入默认门禁；只有对 exact rule 完成独立点时回测后才可作为新增因子。

## 点时回测

当前状态可以用约 360 根日线计算，但资产级门禁不能。对每只拟进入条件推荐的标的，另取尽可能长且不少于约 2,500 个交易日的历史，并在看到结果前冻结评估起点。若数据不足以产生 20 笔非重叠交易，结论必须是 `abstain`，不能借用全历史旧表现或其他标的的结果。

```bash
python3 scripts/backtest_trade_timing.py work/technology-history.json \
  --asset-code 688001 --asset-code 688002 --benchmark-code 515000 \
  --horizon 20 --start 2022-01-01 --cost-bps 20 --slippage-bps 10 \
  --output work/technology-timing-backtest.json
```

上例日期只是可复现实例，不是应回测后移动的参数。实际任务应根据数据截止日预先写下开发段与评估段；没有显式 `--start` 的全历史输出只能诊断，门禁必须 `abstain`。

回测约束：

- 信号在收盘后冻结，最早下一交易日开盘进入；不得按信号日收盘回填成交。
- 每只标的使用非重叠交易，避免同一趋势被重复计数。
- 数据末端不足完整 5/20/60 日持有期的信号一律剔除，不得按截止日提前结算。
- 逐日检查跳空穿越止损和盘中触发止损。
- 扣除显式往返成本与双边滑点。
- 至少 20 笔非重叠交易、平均净收益与平均超额收益为正、净胜率不低于 45%、profit factor 大于 1，资产级门禁才是 `usable`。
- 未模拟涨跌停排队、停牌、成交冲击、精确税费或历史成份变更时必须保留警告。

`model.timing-backtest/1` 的门禁按标的计算。一个标的的结果不能借给另一标的、另一周期或另一组参数。

2026-08-20 的参考审计还发现：现行“2ATR 与 prior 10 日低点取较近者”的硬止损在该面板的 20 日测试段未优于固定 5%，而更宽止损或持有满周期的结果较好但近期超额仍不稳定。因此：

- 不得声称动态止损天然优于固定百分比止损；固定 5% 只作为消融基准，不能跨标的一律采用。
- 不得在看完测试结果后挑选 6%、8%、10% 或 12% 的最佳止损；若默认止损的冻结评估门禁失败，先 `abstain`。
- 同时报告 2ATR、prior 10 日低点和最终技术参考。它们是复核/风险预算输入；是否作为盘中硬止损必须由同一标的、同一规则的点时回测支持。

## 风险和仓位

`compute_trade_timing.py` 输出 2ATR、prior 10 日低点、技术止损参考、止损距离和 2R 复核位。它们是复核参考，不是保证成交价或目标价。

条件推荐的最终仓位同时受三项约束：

```text
最终仓位 <= 单票上限
最终仓位 <= 主题上限分配
最终仓位 <= 每笔风险预算 / 技术止损距离
```

默认每笔风险预算占可投资资产：保守 0.25%、均衡 0.50%、进取 0.75%。若止损距离高于风险档上限、状态不是 `triggered|retest`、或 timing backtest 为 `abstain`，不得给 `条件买入`。

## 事件与技术信号冲突

- 重大利好发生后若价格已 `extended`，机制可以成立但时机仍应等待。
- 重大利空发生后旧的突破状态失效，先重建事件前后价格状态。
- 新闻原稿否定基本面传导时，技术状态不能保留买入结论。
- 技术突破但 A 股相对宽基拒绝外盘共同变量时，至少降为观察并解释本地修正项。
